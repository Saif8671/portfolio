## Overview

A modern, recruiter-friendly portfolio built to showcase work at the intersection of **AI/ML**, **Cybersecurity**, and **Full Stack Development**. Designed for performance, accessibility, and clarity — with animated skill visualizations, filterable project cards, and one-click resume download.

---

## Features

- **Dark / Light mode** — system-aware theme toggle with smooth transition
- **Animated skill charts** — custom SVG pie/donut charts per domain (AI/ML, Security, Full Stack)
- **Filterable project showcase** — cards with tech tags, descriptions, and live/repo links
- **One-click resume download** — CV always accessible from the header
- **Contact section** — smooth-scroll form with client-side validation
- **Performance-first** — Vite build, lazy loading, and optimized assets throughout
- **Accessible** — semantic HTML, ARIA labels, full keyboard navigation
- **Fully responsive** — mobile-first layout across all screen sizes

| Layer | Technology |

| Hosting | Netlify |
| CI/CD | GitHub Actions |

## Local Development

```bash
git clone https://github.com/Saif8671/saif-portfolio.git
cd saif-portfolio
npm install
npm run dev
```

Open `http://localhost:5173`.

To build for production:

```bash
npm run build
```
