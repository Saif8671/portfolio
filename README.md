## ✨ Features

| Feature | Details |
|---|---|
| 🌗 Dark / Light Mode | System-aware theme toggle with smooth transition |
| 📊 Skill Visualizations | Animated SVG pie/donut charts per domain |
| 🗂️ Project Showcase | Filterable cards with tech tags and live links |
| 📄 Resume Download | One-click CV download |
| 📬 Contact Section | Smooth-scroll form with validation |
| ⚡ Performance | Vite build, lazy loading, optimized assets |
| ♿ Accessibility | Semantic HTML, ARIA labels, keyboard navigation |
| 📱 Fully Responsive | Mobile-first layout across all screen sizes |
